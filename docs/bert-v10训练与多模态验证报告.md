## 三、bert-v10（纯文本，生产模型）

```
--focal-gamma 2.0 --label-smoothing 0.1 --user-weight --oversample eda x2
--use-nickname --epochs 3 --lr 1e-5 --seed 42
```

| 指标 | 值 |
|---|---|
| 验证集（10 用户，用户级） | **10/10 正确**（epoch 1） |
| 消息级 ROC-AUC | **0.9224** |
| 校准阈值 | 0.180 |
| 全库预测（674 用户） | 已知标签一致率 **62/71 = 87.3%** |

## 四、bert-v10-multi（文本+头像描述+主页信息）

```
同 v10 参数 + --use-avatar --use-profile（45 头像描述 + 41 主页信息，38 用户有字段）
```

| 指标 | 值 |
|---|---|
| 验证集（用户级） | **9/10**（epoch 1） |
| 消息级 ROC-AUC | **0.4394（< 0.5，负面！）** |
| 校准阈值 | 0.850（严重偏移） |
| 全库一致率 | **58/71 = 81.7%**（低于 v10） |

**结论：头像描述/主页信息以文本拼接方式加入为负面信号**——静态用户级文本被模型过度依赖、泛化失败。

## 五、贴纸通道 LOOCV（零 API）

- 特征：贴纸情感占比（撒娇卖萌/抽象/发呆装傻等 8 类）+ 图率 + 标签覆盖率
- 用户级留一逻辑回归（52 用户：12女/40男）
- **AUC = 0.117（低于随机），女性 0/12 全判错**

**结论：贴纸情感标签单独无性别区分度**。原因：撒娇卖萌贴纸**男性用户使用更频繁**（375569635 男 208 次、3441452166 男 31 次、2760992428 男 9/9），与直觉相反。

## 六、极端用户（图率≥30%）验证

- 全库图率≥30%：**58 人**（其中未标注 28 人）
- 已标注高图率 13 人：**v10 与 v10-multi 均 13/13 正确**
- 案例：2760992428（男，图率 51%，贴纸全为撒娇卖萌）——纯文本模型正确判男

**结论：极端用户（高图率）在当前数据上不构成困难**——他们仍有足够文本信号；真正的无文本用户（如 284256062，113 条全占位符）才是多模态的适用场景，但该类用户无法用文本模型，需要视觉内容通道（未验证，留作后续）。
