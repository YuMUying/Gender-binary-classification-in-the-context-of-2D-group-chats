# FOI 男娘/小众性取向综合指数报告

生成时间：2026-08-20 11:29

## 方法

**混合指数 = 统计特征指数 × 0.65 + BERT 微调概率 × 0.35**（0-100 连续分）

- **BERT 模型**：chinese-roberta-wwm-ext，13 阳性（9 真实 orientation 男 + 4 限量伪标签）vs 56 正常男
- **训练手段**：用户均衡采样 / GRL 用户身份对抗 / 软标签 / 阳性过采样 / Focal Loss
- **统计特征**：男娘话题（男娘/女装/伪娘/丝袜/小裙子/jk/lo裙/白丝/黑丝）+ 稀有萌系（qwq/QAQ/TAT/叭/诶嘿/Orz/OvO）+ 百合/BL/耽美/嗑cp
- **时间轨迹**：每 100 条消息一个窗口，滑窗打分 + 一阶 Kalman 平滑（`foi_curve.csv` / `foi_curves.png`）
- **置信度**：样本 <300 条自动降权；`ci95_foi` 为窗口级 95% 置信区间

## 使用说明

- FOI 是**信号强度指数**（供人工参考），不是身份判定——'谈论男娘'与'自身是男娘'需人工甄别
- 结合性别模型结论交叉参考：模型判 female + FOI 高 = 重点复核对象
- 弱信号'双'标签用户指数居中属正常（性取向光谱）
- 倾向曲线看用户随时间的变化（如是否近期才出现男娘话题）
