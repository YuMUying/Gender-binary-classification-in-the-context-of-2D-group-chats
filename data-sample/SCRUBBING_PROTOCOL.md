# 脱敏与抽样规程（SCRUBBING PROTOCOL）

版本：R6-2026-09-08｜生成脚本：`build_sample.py`（本目录，固定种子 42 可复现）

## 1. 来源与排除

- 来源：某社交平台兴趣群聊主库（302 万条）中选取 7 个群：4 个男性主导二次元兴趣群（anime-1..4）与 3 个女性主导乙女游戏玩家群（otome-1..3）。真实群号与群名不发布，仅保留类别标签。
- **排除**（消息样例中完全不出现其文本）：
  1. 标注账本全部已标注说话人（含冻结快照 190 人及后续新增标注者）——账本文本不公开，其字段以脱敏标注表形式单独发布；
  2. 作者本人账号；
  3. 系统账号与群机器人（uid≤0、Q群管家等）；
  4. 空文本消息。
- 现实关系群（同乡/班群）整类不进入样例（文本含真实姓名概率高）。

## 2. 抽样

- anime-1..4 分层随机抽样（6000/4000/3500/1500 条，种子 42）；
- otome-1..3 **全量发布**其非账本部分（969/2135/11770 条），使第三方可完整复现论文 §5.5 的跨社群原型扫描（零命中）；
- 最终样例 29,874 条。

## 3. 字段级脱敏

| 字段 | 处理 |
|---|---|
| 说话人 | 随机别名 SPK_xxxx（样例内一致，映射不发布；与标注表 LED_xxx 两套独立映射，互不可连） |
| 时间 | 时间戳粗化为"日"（UTC+8） |
| 群标识 | 群号/群名 → 类别标签 anime-N / otome-N |
| 昵称/群名片 | 整体不导出 |
| 消息序号 | 重编 msg_id（1..N），与原库消息 id 无对应关系 |

## 4. 文本自动清洗（规则 R6-2026-09-08）

按序执行，命中替换为占位符：

1. 全角数字 → 半角；
2. URL（http/https/www）→ `[链接]`；
3. 邮箱地址 → `[邮箱]`；
4. 手机号（1[3-9] 开头 11 位）→ `[号码]`；
5. 独立 5–11 位数字串（QQ 号形态）→ `[数字]`；
6. 残留 @提及 → `@`；
7. 空白折叠为单空格。

导出源已预先剥离他人昵称（@提及与引用回复头），本规程为二次防线。

## 5. 人工审计

- 随机抽取 300 条（种子 43）人工复核：以"可识别个人身份的信息（号码/真名/链接/账号）"与"可定位到具体自然人的叙述"两项为不合格标准；
- 2026-09-08 审计结果：**0 条不合格**（审计员=作者；`audit/random_audit.csv` 为审计子样本原件）；
- 规则误伤说明：规则 5 会把所有 5–11 位数字串替换为占位符，极少数含数字的正常表述（如游戏数值）会被一并移除——宁可误伤，不漏标识。

## 6. 已知残留风险（如实声明）

- 文本为自然语言原貌（含粗口语），未做情感或敏感词过滤；
- 极低概率存在未被规则与审计覆盖的间接身份线索（如昵称式自称、特定事件叙述）。发现者请通过仓库 Issue 反馈，作者将在下一版本中移除并更新版本号。
